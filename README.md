# Портфолио Давида Хачатряна

Статический сайт с каталогом из 47 проектов и учебных подборок, сгруппированных по основному языку.

- [Опубликованный сайт](https://davitmirea0.github.io/frontend-and-backend-practice/)
- [Каталог проектов](https://davitmirea0.github.io/frontend-and-backend-practice/pages/projects.html)
- [Исходники по языкам](projects/README.md)

## Локальный просмотр

Откройте `index.html` в браузере или запустите статический HTTP-сервер из корня репозитория. Сборка и установка зависимостей для самого портфолио не нужны. Каталог виден без JavaScript; поиск и фильтр добавляются при его включении.

## Структура

`pages/projects.html` — каталог, `scripts/projects.js` — фильтрация, `style/styles.css` — стили, `projects/<язык>/<проект>/` — копии исходников. `projects/catalog.json` содержит метаданные каталога.

Проекты запускаются независимо друг от друга. Сначала прочитайте `PORTFOLIO.md` и исходный README внутри нужного каталога. Зависимости, готовые сборки, локальные базы и секреты в архив исходников не включены. Запуск всех приложений и их тестов при переносе не проверялся.

Часть работ — учебные задания и доработки тестовых проектов; это отражено в описаниях. `.nojekyll` отключает обработку исходников через Jekyll.
