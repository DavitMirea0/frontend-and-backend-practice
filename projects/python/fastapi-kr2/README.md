|-------|---------------------|-----------------------------------|

## Задание 5.1 — Аутентификация на основе cookie

Простая аутентификация: при логине устанавливается httponly cookie `session_token` с UUID-значением.

| Метод | URL      | Описание                              |
|-------|----------|---------------------------------------|
| POST  | `/login` | Логин (username + password), установка cookie |
| GET   | `/user`  | Профиль пользователя (требует cookie) |

Технологии: FastAPI, uuid

## Задание 5.2 — Cookie с криптографической подписью

Cookie формата `<user_id>.<signature>`, подпись вычисляется через HMAC-SHA256.

| Метод | URL              | Описание                                  |
|-------|------------------|-------------------------------------------|
| POST  | `/login_signed`  | Логин с установкой подписанной cookie      |
| GET   | `/profile_signed`| Профиль с проверкой подписи               |

Технологии: FastAPI, hmac, hashlib, uuid

## Задание 5.3 — Динамическое время жизни сессии

Cookie формата `<user_id>.<timestamp>.<signature>`. Сессия автоматически продлевается при активности пользователя: если прошло менее 3 минут — cookie не обновляется, от 3 до 5 минут — продлевается, более 5 минут — сессия завершается (401).

| Метод | URL              | Описание                                      |
|-------|------------------|-----------------------------------------------|
| POST  | `/login_session` | Логин с установкой cookie с timestamp          |
| GET   | `/profile`       | Профиль с динамическим продлением сессии       |

Технологии: FastAPI, hmac, hashlib, uuid, time

## Задание 5.4 — Работа с заголовками запроса

Извлечение заголовков `User-Agent` и `Accept-Language`, валидация формата, ошибка 400 при отсутствии или неверном формате.

| Метод | URL        | Описание                            |
|-------|------------|-------------------------------------|
| GET   | `/headers` | Извлечение и валидация заголовков   |

Технологии: FastAPI, Header

## Задание 5.5 — Модель CommonHeaders (DRY)

Переиспользуемая Pydantic-модель `CommonHeaders` для извлечения заголовков. Маршрут `/info` дополнительно возвращает заголовок ответа `X-Server-Time`.

| Метод | URL         | Описание                                          |
|-------|-------------|----------------------------------------------------|
| GET   | `/headers2` | Заголовки через CommonHeaders                      |
| GET   | `/info`     | Заголовки + сообщение + X-Server-Time в ответе     |

Технологии: FastAPI, Pydantic, datetime
