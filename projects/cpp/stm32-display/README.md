# Лабораторная работа 2 — семисегментный индикатор

Проект для STM32F407VGT6, VS Code и PlatformIO. Код на C использует
регистры CMSIS, без вызовов HAL и Arduino. Пакет STM32Cube предоставляет
заголовки и стартовый код. По умолчанию запускается `lab2_all`.

## Подключение

| Выводы | Назначение |
|---|---|
| PA0, PA1, PA2, PA3, PA4, PA5, PA6 | Сегменты a, b, c, d, e, f, g |
| PA7 | Точка dp |
| PC0, PC1, PC2, PC3 | Разряды слева направо |
| PB0 | Кнопка на GND; внутренняя подтяжка к питанию |
| GND | Общий провод стенда и внешнего генератора |

Схема по умолчанию — общий катод: сегмент включается единицей,
разряд включается нулем. Каждый сегмент подключается через резистор
220–330 Ом. Используйте предусмотренный стендом каскад управления
разрядами; его активный уровень должен соответствовать настройке.
Если драйвер инвертирует сигнал, измените `DIGIT_ACTIVE_LOW`.
Настройки полярности и порядка разрядов находятся в `include/lab_config.h`.

## Режимы

| Окружение PlatformIO | Результат |
|---|---|
| static_digit | Цифра 5 на одном разряде |
| dynamic_year | Число 2026 на четырех разрядах |
| button_year | 2026; при PB0 = 0 — год рождения, задание 5.1 |
| lab2_all | Переключение годов и точка, задания 5.1 и 5.2 |
| seconds_counter | Счетчик 0000–9999 секунд, задание 5.3 |

В `include/lab_config.h` замените `BIRTH_YEAR = 2005U` на свой год.
`DP_POSITION` задает позицию точки: 0 — крайняя левая, 3 — крайняя правая.
Кнопка действует по уровню: пока нажата, показывается год рождения;
после отпускания возвращается 2026. Счетчик запускается отдельным режимом.

## Запуск в VS Code

1. Установите расширение PlatformIO IDE.
2. Распакуйте архив и откройте папку `STM32_Lab2`, содержащую `platformio.ini`.
3. Откройте PlatformIO → Project Tasks и выберите окружение из таблицы.
4. Нажмите Build, затем подключите ST-LINK и нажмите Upload.
5. При первой сборке PlatformIO загружает платформу и пакеты из интернета.

Команды в терминале PlatformIO:

```sh
pio run -e lab2_all
pio run -e lab2_all -t upload
pio run -e seconds_counter
pio run -e seconds_counter -t upload
```

Загрузка прошивки заменяет текущую программу микроконтроллера.
Готовые файлы после сборки находятся в `.pio/build/<окружение>/`:
`firmware.elf` и `firmware.bin`.

## Устройство программы

- `gpio_init` настраивает PA0–PA7, PC0–PC3 и PB0.
- `digit_code` содержит коды цифр 0–9.
- `show_digit` сначала гасит разряды, затем меняет сегменты и включает нужный разряд.
- `SysTick_Handler` считает миллисекунды; таймер настраивается по `SystemCoreClock`.
- Каждые 2 мс обновляется один разряд, полный цикл занимает около 8 мс.
- В режиме счетчика каждые 1000 мс увеличивается число секунд.

Точность счета зависит от источника тактирования. Во время остановки
программы отладчиком индикация и отсчет могут прерываться.

## Проверка на стенде

Проверьте цифру 5, порядок разрядов числа 2026, переключение по PB0,
точку во втором разряде слева и изменение счетчика раз в секунду.
Для ускоренной проверки переполнения временно задайте `seconds = 9998U`.
Снимки этих режимов можно вставить в оставленные места отчета.

Конфигурация платы: https://docs.platformio.org/en/latest/boards/ststm32/genericSTM32F407VGT6.html

## Проверка сборки

Все пять окружений успешно собраны с платформой ST STM32 20.0.0,
STM32CubeF4 1.28.3 и ARM GCC 7.2.1. Предупреждения о неиспользуемых
параметрах относятся к исходникам библиотеки STM32Cube.
На физическом стенде проект не проверялся.

В папке `firmware` находятся собранные BIN-файлы пяти режимов для
стандартных настроек подключения и года рождения 2005.
Адрес начала записи во Flash — `0x08000000`. После изменения настроек
пересоберите проект: готовые BIN-файлы автоматически не обновляются.
