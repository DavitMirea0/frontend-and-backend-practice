# Результаты проверки

## Обновление Docker Compose

Добавлен запуск приложения в Java 17 контейнере, подключённом к PostgreSQL по адресу `db:5432`. `run.cmd` выполняет `docker compose run --build --rm app`. Порт PostgreSQL на Windows не публикуется; Excel сохраняется через bind mount `exports`. Dockerfile устанавливает шрифты и fontconfig для Apache POI.

`docker compose --profile cli config --quiet` выполнен успешно. Сборка образа и запуск контейнеров в текущем окружении не проверены: движок Docker Desktop недоступен, обращение к WSL возвращает `E_ACCESSDENIED`. Приведённые ниже результаты тестов Java относятся к ранее проверенной версии приложения; Java-код при настройке Compose не менялся.

## Проверки Java-приложения

Проверено 16.09.2026 на Windows, JDK 17, Maven 3.9.9 и настоящей PostgreSQL 16.6. Проверочная БД запущена отдельно на порту 55439. Docker Compose подготовлен для запуска проекта, но сам Docker-сценарий в этом окружении не выполнялся: движок Docker Desktop не был запущен.

- `mvn clean package`: BUILD SUCCESS.
- 8 тестов: 0 ошибок, 0 падений, 0 пропусков, включая интеграционный тест PostgreSQL.
- Установка SQL: 5 сотрудников, 10 заявок, 17 единиц оборудования, 5 статусов.
- Модульные тесты: обязательные поля, количество, отсутствующий сотрудник, email, смена статусов, ограничения редактирования и удаления, поиск, фильтрация, сортировка, статистика.
- Консольные тесты: текст вместо числа, неверный ID, отсутствующая запись, возврат в меню после ошибки, недоступная БД.
- JDBC: создание, чтение, изменение и удаление, UNIQUE email, запрет удаления сотрудника с заявками, CHECK количества, защита смены статуса от устаревшего значения.
- Excel выгружен Java-приложением из PostgreSQL и повторно прочитан Apache POI. Проверены два листа, число записей и числовой тип даты.
- Оба листа визуально проверены через предварительный просмотр. Визуализатор импорта показал даты серийными числами; корректный формат даты в самом XLSX отдельно проверен Apache POI DataFormatter: `01.09.2026 10:00`.

Рабочий файл `examples/equipment-demo.xlsx` содержит только начальные учебные данные. Тестовые записи удалены. Пропуски в последовательностях ID после интеграционных тестов допустимы.

Для повторения проверок см. раздел «Проверки» в README. Для запуска поставляемого JAR необходима Java 17+ и доступная PostgreSQL со схемой проекта.
