## 📋 Что реализовано

### 1. HTTP-Сервер (HttpListener)
- Запуск/остановка сервера с настройкой порта через UI
- GET-запросы: возвращают статус сервера (кол-во запросов, uptime, статистику)
- GET /messages: список всех сохранённых сообщений
- POST-запросы: принимают JSON `{"message": "текст"}`, сохраняют и возвращают ID
- Логирование всех запросов (метод, URL, заголовки, тело) в текстовое поле и файл
- Многопоточная обработка запросов (Task.Run + async/await)

### 2. HTTP-Клиент (HttpClient)
- GET-запросы на внешние API (jsonplaceholder.typicode.com)
- POST-запросы с JSON-телом на локальный сервер
- Настройка URL, метода (GET/POST) и тела запроса через UI
- Отображение ответа, статус-кода и времени выполнения

### 3. Мониторинг и аналитика
- Сводная статистика: всего запросов, GET/POST, среднее время, uptime
- Столбчатая диаграмма нагрузки по минутам
- Таблица всех логов (DataGrid) с сортировкой
- Фильтрация по: методу (GET/POST), направлению (входящий/исходящий), статусу (2xx/4xx/5xx)
- Автоматическое сохранение логов в файл `logs.txt`

## 🚀 Как запустить

### 1. Создание проекта в Visual Studio

1. Откройте **Visual Studio 2022**
2. `File → New → Project` → **WPF Application** (.NET)
3. Назовите проект `HttpMonitor`
4. Выберите **.NET 8.0**

### 2. Установка NuGet-пакетов

```powershell
Install-Package Newtonsoft.Json
```

> LiveCharts.Wpf указан в .csproj, но в данной версии график реализован через ItemsControl без внешних зависимостей. Пакет можно не устанавливать.

### 3. Структура файлов

Скопируйте файлы из архива в проект:

```
HttpMonitor/
├── HttpMonitor.sln
└── HttpMonitor/
    ├── HttpMonitor.csproj
    ├── App.xaml / App.xaml.cs
    ├── MainWindow.xaml / MainWindow.xaml.cs
    ├── Models/
    │   ├── RequestLogEntry.cs
    │   ├── StoredMessage.cs
    │   └── ServerStatistics.cs
    └── Services/
        ├── HttpServerService.cs
        ├── HttpClientService.cs
        └── LogService.cs
```

### 4. Запуск

Нажмите `F5` или `Ctrl+F5`.

## 🧪 Как тестировать

### Тест 1: Запустить сервер
1. На вкладке **Сервер** укажите порт (например, 5000)
2. Нажмите **Запустить сервер**
3. Статус сменится на зелёный

### Тест 2: GET-запрос на внешний API
1. Перейдите на вкладку **Клиент**
2. Метод: GET, URL: `https://jsonplaceholder.typicode.com/posts`
3. Нажмите **Отправить запрос** — увидите JSON-ответ

### Тест 3: GET-запрос на свой сервер
1. Метод: GET, URL: `http://localhost:5000/`
2. Отправить — увидите статус сервера

### Тест 4: POST-запрос на свой сервер
1. Метод: POST, URL: `http://localhost:5000/`
2. Тело: `{"message": "Привет!"}`
3. Отправить — получите ID сообщения

### Тест 5: Мониторинг
1. Перейдите на вкладку **Мониторинг**
2. Увидите статистику и таблицу логов
3. Нажмите **Обновить график** для диаграммы нагрузки
4. Используйте фильтры для поиска конкретных запросов
