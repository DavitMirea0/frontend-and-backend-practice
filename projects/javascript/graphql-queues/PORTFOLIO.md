# GraphQL и очереди задач

React-клиент и GraphQL API для книг и задач; RabbitMQ consumer с повторными попытками и DLQ.

Стек: JavaScript, React, GraphQL, RabbitMQ, Docker.

Это копия исходников для портфолио. Зависимости, сборки, локальные базы и секреты не включены. Перед запуском установите зависимости по манифестам проекта и настройте окружение. Если есть README, используйте его инструкции; пути к готовым бинарным сборкам в исходном README относятся к оригинальной локальной поставке.
