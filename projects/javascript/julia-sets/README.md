# Множества Жюлиа

Демо к докладу «Комплексные числа в программировании» (листок 2, задача 2.9).

## Запуск

Нужен Node.js 20 или новее. Зависимостей нет, `npm install` не нужен.

    node server.mjs

Откройте http://localhost:3000 (на Windows можно запустить `start.cmd`).
Другой порт: `PORT=3001 node server.mjs` (в PowerShell: `$env:PORT=3001; node server.mjs`).

Тесты: `node --test`

## Что внутри

- `lib/julia.mjs` — математика: шаг итерации для трёх функций, подсчёт картинки, орбита точки.
- `server.mjs` — Node.js сервер: `/api/julia` (картинка, байты), `/api/orbit` (первые 10 шагов точки), статика.
- `public/` — страница: холст, ползунки c, лимит итераций, порог, окно, палитры.

## Для показа

1. Кнопки слева это четыре функции из задачи: два значения c и две дробные функции.
2. Ползунки Re c и Im c показывают, что от одного параметра картинка меняется целиком.
3. Клик по картинке показывает орбиту точки: модуль растёт и превышает порог, значит точка убежала.
4. Под картинкой видно, сколько пикселей и шагов в худшем случае (слайд 8 про ограничения).

Цвет задаётся числом: номер итерации побега делится на лимит. Белый (в палитре «Огонь») значит, что точка не убежала за лимит.
