# Бильярд: математика движения

Учебное приложение на React + Node.js по заданию 3.2 третьего листка. Готовая сборка входит в комплект.

## Запуск

Нужен Node.js 22 или новее. Откройте `start.cmd` в Windows или выполните из этой папки:

```sh
node server.mjs
```

Перейдите на http://localhost:3002. Для готовой сборки интернет и установка пакетов не нужны. Не открывайте `dist/index.html` двойным щелчком: нужен локальный сервер. Остановка: Ctrl+C в терминале. Если порт занят, в PowerShell выполните `$env:PORT=3003; node server.mjs` и откройте порт 3003.

## Демонстрация за 25 секунд

1. «Замкнутая», затем «Показать полный период»: t ≈ 13,42 с, координаты снова (1,20; 1,80), скорость (1,79; 0,89).
2. «Развёртка»: одна прямая через зеркальные копии поля.
3. «Незамкнутая», затем «Показать 30 секунд»: другой рисунок траектории.

Запуск, пауза и сброс управляют временем. Угол, скорость, размеры и начальную точку можно изменить. Все изменения условий сбрасывают время. Начальную точку задают щелчком внутри исходного поля или числовыми полями справа; она ограничена внутренностью прямоугольника. При скрытии вкладки движение ставится на паузу. Максимум одного запуска — 120 секунд. При запуске с конца отсчёт начинается заново.

## Модель

Оси x вправо, y вверх. Длины в условных единицах, время в секундах. Шар — материальная точка, без трения и луз. Отражение от вертикальной стенки меняет знак vx, от горизонтальной — vy. В точный момент столкновения показывается исходящая скорость. В углу программа меняет оба знака: это соглашение, которым продолжается особая траектория.

Развёрнутые координаты: X = x0 + vx*t, Y = y0 + vy*t. Положительный остаток `mod(q,n) = ((q%n)+n)%n`. Возврат: `x = a - abs(mod(X,2*a)-a)`, аналогично для y с b. Координаты вычисляются непосредственно по времени, след включает точные моменты пересечения стен. Из-за округления чисел это численная модель, а не точная символьная арифметика.

Пресеты используют точные выражения `.5` и `Math.SQRT2`, а не округлённое показание угла на экране. Оба сбрасывают поле к квадрату 6×6, скорость к 2, точку к (1.2,1.8). При изменении угла используется новое значение в градусах. Для прямоугольника критерий периода — рациональность `(a*vy)/(b*vx)` при ненулевых компонентах. Для движения вдоль одной оси период существует отдельно. Иррациональность отношения нельзя установить по конечной картинке и числам JavaScript.

## Разработка

```sh
npm ci
npm run build
npm test
```

Интернет нужен только для установки зависимостей при разработке. React и React DOM 19.3.0, esbuild 0.28.2 зафиксированы в package-lock.json.

- `lib/model.mjs` — математика и часы анимации.
- `src/main.jsx` — интерфейс React и рисунок Canvas.
- `src/style.css` — адаптивное оформление.
- `server.mjs` — HTTP-сервер Node.js без внешних серверных зависимостей.
- `test/model.test.mjs` — 9 тестов: стенки, угол, скорость, независимый событийный расчёт, период, след, часы, валидация, HTTP.

Математический источник: H. Masur, S. Tabachnikov, *Rational billiards and flat structures*, §§ 1.3–1.4, https://math.uchicago.edu/~masur/handbook1.pdf .
