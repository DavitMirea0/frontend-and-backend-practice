# Случайная встреча: лаборатория Монте-Карло

Учебный сайт на React + Node.js по задаче 4.6 П. Е. Рябова. Приход A и приход B независимы и равномерны на интервале 0–60 минут после 14:00. A ждёт 10 минут, B — 12. Параметры можно менять.

## Запуск готовой версии

Нужен Node.js 22 или новее. Запустите `start.cmd` в Windows или из этой папки выполните:

```sh
node server.mjs
```

Откройте http://localhost:3003. Готовая сборка лежит в `dist/`; для показа не нужны интернет или установка зависимостей. Не открывайте index.html напрямую. Для остановки сервера нажмите Ctrl+C. Если порт занят, задайте другой: в PowerShell `$env:PORT=3004; node server.mjs`, затем откройте порт 3004.

## Демонстрация

«Пример для доклада» устанавливает ожидания 10 и 12 минут, seed 46 и 150 000 опытов, затем запускает расчёт. Результат: 49 793 встречи, 33,195333…%; теория: 599/1800 = 33,277777…%; абсолютное отклонение: 0,082444… процентного пункта.

Измените ожидание A до 30 минут, оставив B = 12: теория станет 55,50%. Нажмите «Запустить» и сравните результат. Параметры всегда сбрасывают накопленную серию. «Пауза» сохраняет результаты и состояние генератора, «Запустить» продолжает расчёт. «Повторить» после завершения повторяет ту же серию. «Сброс» очищает данные. «Новая случайная серия» выбирает другой seed и очищает результаты; запуск выполняется отдельно. Кнопки +1 и +1 000 добавляют заданное число опытов, не превышая выбранный итоговый N.

## Математика

Встреча: `y-x <= waitA && x-y <= waitB`, то есть `-waitB <= y-x <= waitA`. Это равносильно пересечению интервалов присутствия [x,x+waitA] и [y,y+waitB]. Граничное равенство включено.

При ожиданиях от 0 до 60 точная вероятность:

`P = 1 - ((60-waitA)^2 + (60-waitB)^2) / 7200`.

Это единица минус относительная площадь двух угловых треугольников. При нулевых ожиданиях вероятность равна 0, при ожиданиях 60 и 60 — 1, при 15 и 15 — 7/16.

Оценка Монте-Карло `pHat = hits/N`. До первого опыта оценки нет. Отклонение показывается в процентных пунктах: `100*abs(pHat-P)`. Условие встречи проверяется для каждой сгенерированной пары, а не заменяется готовым распределением с известной вероятностью.

## Воспроизводимость и графики

Генератор Mulberry32, начальное целое значение seed от 0 до 4 294 967 295. Это учебная псевдослучайная последовательность, не криптографический источник. Фиксированный seed позволяет повторить результат. Отрисовка и паузы не расходуют случайные числа.

Точки на квадрате — только первые 800 опытов. Итоговые счётчики учитывают все N. История частоты сохраняет первые 10 опытов и затем каждый сотый; при отображении длинная линия прореживается примерно до 600 точек с обязательным показом последнего результата. На сайте вертикальная шкала 0–100%, горизонтальная — от 0 до выбранного N. В презентации шкала графика увеличена, это указано на слайде.

## Разработка

```sh
npm ci
npm run build
npm test
```

Для установки зависимостей разработки нужен интернет. React и React DOM 19.3.0, esbuild 0.28.2 зафиксированы в lock-файле. Node-сервер не имеет внешних зависимостей. Расчёт и графика работают в браузере, React управляет состоянием. HTTP-сервер раздаёт только index.html, app.js и app.css.

- `lib/model.mjs`: событие, формула, генератор и серия опытов.
- `src/main.jsx`: интерфейс, Canvas с точками и SVG-график частоты.
- `src/style.css`: адаптивная вёрстка.
- `test/model.test.mjs`: 9 тестов, включая точную формулу, независимую сеточную проверку, граничные случаи, воспроизводимость и HTTP.

Источники: задача 4.6 предоставленного листка; H. Pishro-Nik, § 7.1.1: https://www.probabilitycourse.com/chapter7/7_1_1_law_of_large_numbers.php .
