### Запуск

Для запуска необходимо написать: 
## git clone
Далее необходимо перейти в папку проекта и написать: 
## npm start
Еще необходимо установить mui
Для этого вводим следующую команду: 
## npm install @mui/material @emotion/react @emotion/styled @mui/icons-material
Пишем npm start и запускаем
