# Формула / Матрица

Учебный проект к докладу «Матрицы в программировании: анализ ошибок в учебном квизе».

## Быстрый запуск

Нужен установленный Node.js 22 или новее. Готовая сборка уже включена, интернет и установка пакетов для запуска не нужны.

1. Распакуйте архив целиком.
2. Откройте терминал в папке `physics-quiz`.
3. Выполните `node server.mjs`.
4. Откройте `http://localhost:3000` в браузере.

На Windows также можно запустить `start.cmd` двойным щелчком. Окно сервера нужно оставить открытым. Чтобы остановить сервер, нажмите Ctrl+C в его терминале. Сервер доступен только на этом компьютере.

## Показ на защите за 30 секунд

Нажмите «Пример для доклада». Это явно помеченный демонстрационный набор ответов, совпадающий со слайдами: ошибки в вопросах 1, 3 и 4. Общий результат — 3/6. Покажите доли ошибок 50%, 100%, 0% и формулу `e = Mᵀr`. Раскройте третий ответ с формулой кинетической энергии. При желании нажмите «Повторить: Динамика и энергия».

## Математическая модель

- `M` имеет размер n × 3. Строки — вопросы, столбцы — кинематика, динамика и энергия, термодинамика.
- `M[i][j] = 1`, если вопрос i относится к теме j, иначе 0. В каждой строке ровно одна единица.
- `r[i] = 1` при ошибке, `r[i] = 0` при правильном ответе.
- `e = Mᵀr` — вектор числа ошибок.
- `c = Mᵀ1` — вектор числа вопросов по темам.
- `p[j] = e[j]/c[j]` при `c[j] > 0`. При `c[j] = 0` возвращается `null` («Нет данных»).
- Рекомендуются все темы с максимальной положительной долей ошибок. При отсутствии ошибок рекомендации нет.

Это прозрачная эвристика по текущей попытке. Она не учитывает сложность и угадывание, не является моделью машинного обучения и не измеряет знания с заданной точностью. Тематическое повторение включает все шесть вопросов выбранной темы, в том числе уже встречавшиеся. Данные попыток не сохраняются после перезагрузки страницы.

## Структура

- `src/main.jsx`, `src/style.css` — интерфейс React.
- `server.mjs` — HTTP-сервер на Node.js и проверка ответов.
- `lib/matrix.mjs` — матричный анализ.
- `data/questions.mjs` — 18 вопросов с ответами, пояснениями и страницами источников.
- `test/matrix.test.mjs` — проверки расчётов и HTTP API.
- `dist/` — готовая сборка для автономного запуска.

## Изменение и пересборка

При наличии интернета: `npm ci`, затем `npm run build`. Для запуска готовой сборки — `npm start`. Если политика npm блокирует install scripts, может потребоваться разрешение штатного postinstall для esbuild. Тесты: `npm test` (либо `node --test --test-isolation=none test/*.test.mjs` при запрете дочерних процессов).

Версии пакетов зафиксированы в `package-lock.json`. После редактирования React/CSS нужна пересборка. После изменения серверного кода перезапустите Node.js.

Если порт 3000 занят, в PowerShell задайте `$env:PORT=3001`, затем запустите сервер и откройте `http://localhost:3001`.

## Источники

Учебные PDF пользователя: «Листок № 1. СЛАУ, матрицы, квадратичные формы», составитель П. Е. Рябов (связь с темой матриц, задача 1.4); «Конспект с формулами — механика», с. 1, 2, 4, 5; «Конспект с формулами — молекулярка», с. 1. Исходные PDF не включены в архив.

Формулировки вопросов уточняют условия применимости: постоянное ускорение, инерциальная система, идеальный газ, температуры в кельвинах и соглашение о знаке работы. Спорное обобщение из конспекта о равенстве адиабатического и изоэнтропического процессов не используется: это равенство требует обратимости.

Документация: https://react.dev/learn/state-a-components-memory и https://nodejs.org/api/http.html. Математический алгоритм и демонстрационный набор разработаны для этого проекта.
